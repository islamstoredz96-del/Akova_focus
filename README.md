# akova-focus

A professional Android focus and productivity app with native scheduling, protection, prayer, and sleep systems.

Akova Focus is a comprehensive Android application built natively with Kotlin and Jetpack Compose, designed to help users manage their time through structured programs, days, and tasks. It features a sophisticated scheduling engine, a protection system using Accessibility Service and overlays, prayer time calculations, sleep management, notifications, progress tracking, AI integration, authentication, and cloud sync. The app is fully localized in Arabic, English, and French with complete RTL support and a polished Material 3 design.

## 📱 تحويل المشروع إلى APK / Build Android APK

### الطريقة الأولى: محليًا (يحتاج JDK 17 + Android SDK)
```bash
npm install
npm run android:init     # أول مرة فقط — يضيف مجلد android/
npm run android:sync     # build + cap sync
npm run android:apk      # ينتج app-debug.apk
```
الناتج: `android/app/build/outputs/apk/debug/app-debug.apk`

### الطريقة الثانية: عبر GitHub Actions (بدون أي إعداد محلي)
ارفع المشروع إلى GitHub، وسيقوم `.github/workflows/android-apk.yml` ببناء الـ APK تلقائيًا وإتاحته كـ artifact.

### الطريقة الثالثة: PWABuilder
ارفع البناء إلى أي استضافة، ثم استخدم <https://www.pwabuilder.com/> لتوليد APK سريعًا.
